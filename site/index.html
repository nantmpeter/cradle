为什么选择 Cradle

摇篮孕育，不惧成长

大多数后台框架逼你做取舍——搭建速度 vs. 长期可维护性。Cradle 消除了这个两难。

01

抗压不裂

Rust + Axum 从根上消灭一整类运行时 bug。无 GC 停顿，无生产环境空指针。你的摇篮不会在压力下碎裂。

内存安全 零 GC 停顿 编译时检查
02

三路出击

管理后台、移动端 App、第三方接入——各自拥有独立认证的 API 层。一个底座，所有方向。

Admin API App API Open API

自带说明书

约定优于配置 7 层标准模式 即插即用

能力就绪

SSE 推送通知、HMAC 签名 Webhook、OpenAPI 文档——不是上线后才补的功能，而是从摇篮里就准备好的能力。

功能特性

开箱即用的企业级能力

从用户管理到 API 基础设施，覆盖后台管理系统的核心场景。

多层认证体系

JWT 双 Token 刷新、TOTP 两步验证、API Key + Scope 权限、OAuth2 第三方登录（GitHub/Google），以及短信验证码登录。

三层路由架构

Admin API（JWT+RBAC）、App API（移动端）、Open API（第三方接入），独立认证链路 + 统一错误格式，路由版本化 + 旧版兼容。

Webhook + API Key

API Key 粒度权限控制（Scope），Webhook 事件订阅 + HMAC-SHA256 签名投递 + 指数退避重试，满足第三方集成需求。

Rust 高性能后端

Axum 异步框架 + SQLx 零开销数据库驱动 + PostgreSQL，极致性能表现。编译时类型安全，消除运行时空指针等隐患。

现代前端体验

React 19 + shadcn/ui + Tailwind CSS v4，支持 8 色主题定制、暗黑模式、i18n 中英双语、SSE 实时通知、Tab 导航。

全面测试覆盖

61 个集成测试覆盖认证、RBAC、API Key、Webhook 等核心模块。Request ID 全链路追踪，统一错误码体系。

快速开始

3 分钟启动项目

零配置数据库初始化，开箱即用的默认管理员账号。

Terminal
# 1. 克隆项目
$ git clone https://github.com/your-org/cradle.git
$ cd cradle
# 2. 启动数据库
$ docker compose up db -d
# 3. 启动后端（自动迁移）
$ cd apps/backend
$ cp config/default.toml config/local.toml
$ cargo run
# → http://localhost:8080
# 4. 启动前端
$ cd ../frontend
$ pnpm install && pnpm dev
# → http://localhost:5173
# 默认账号: admin@example.com / Admin@1234
